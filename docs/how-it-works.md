# 项目实现原理

这个项目分成两层：

## 1. 桌面端显示层汉化

通过给便携版前端页面注入 `skill-display-patch.js`：

- 监听 DOM 变化
- 替换技能名称
- 替换 tooltip / title / aria-label
- 对未覆盖英文自动调用在线翻译
- 把翻译结果缓存到浏览器本地存储

这属于“显示层补丁”：

- 不改真实命令名
- 不改真实技能 ID
- 不破坏原有功能

## 2. 技能元数据中文同步

通过 `sync_skill_chinese.py`：

- 扫描 `~/.codex/skills`
- 扫描 `~/.codex/plugins`
- 为技能写入中文 `display_name`
- 为技能写入中文 `short_description`
- 生成 `技能作用.txt`
- 输出 `skill_display_map.json` 给前端补丁使用

## 3. 为什么新增技能也能自动汉化

因为安装后会创建 watcher：

- 开机自动启动
- 轮询技能目录变化
- 检测到新增技能时重新同步
- 前端定时读取新映射

## 4. 为什么既要“同步器”又要“前端补丁”

因为只做其中一个都不够：

- 只改技能元数据：有些内置命令和 tooltip 还是英文
- 只改前端补丁：新技能没有中文元数据时体验不完整

两个一起用，效果最好：

- 技能本身尽量中文
- 界面显示也尽量中文
- 漏网项还能自动翻译缓存
